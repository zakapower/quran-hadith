# Progressive Web App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Tilāwah installable and offline-capable for visited pages plus auto-cached played chapter audio (no install/download UI).

**Architecture:** `@serwist/next` wraps `next.config.ts`, builds `app/sw.ts` → `public/sw.js`. Manifest + PNG icons enable installability. Runtime NetworkFirst for navigations (fallback `/offline`); CacheFirst for `/api/quran-audio` (max 32, purge on quota). SW disabled in development.

**Tech Stack:** Next.js 15 App Router, TypeScript, `@serwist/next`, `serwist`, static PNG icons.

**Spec:** `docs/superpowers/specs/2026-08-13-pwa-design.md`

## Global Constraints

- No custom install banner / «Install» control / `beforeinstallprompt` UI.
- No download-manager UI; audio caches only via SW when the player hits `/api/quran-audio`.
- Offline miss → `/offline` only (links to `/`, `/quran`, `/hadith`, `/favorites`).
- Manifest `theme_color` / `background_color`: `#101512`.
- Audio cache: CacheFirst, **32** entries LRU, `purgeOnQuotaError: true`; cache only status **200** (not 206 Range).
- SW disabled when `process.env.NODE_ENV === 'development'`.
- Do not add `/offline` to `sitemap.ts`.
- Rollback: revert commits from this plan if needed (`git revert` / `git reset` per user).
- Verify with `npx tsc --noEmit` and `npm run build` (no unit-test harness in repo).

Create `scripts/generate-pwa-icons.mjs`:

```js
import { mkdir, readFile } from 'node:fs/promises'
import path from 'node:path'
import sharp from 'sharp'
import { fileURLToPath } from 'node:url'

const root = path.join(path.dirname(fileURLToPath(import.meta.url)), '..')
const outDir = path.join(root, 'public', 'icons')
const svgPath = path.join(root, 'public', 'favicon.svg')

await mkdir(outDir, { recursive: true })
const svg = await readFile(svgPath)

async function writePng(name, size, { padded = false } = {}) {
  const side = size
  let pipeline = sharp(svg).resize(side, side, { fit: 'contain', background: '#2f5d4a' })
  if (padded) {
    // ~20% safe zone for maskable
    const inner = Math.round(side * 0.8)
    const pad = Math.round((side - inner) / 2)
    const innerBuf = await sharp(svg)
      .resize(inner, inner, { fit: 'contain', background: '#2f5d4a' })
      .png()
      .toBuffer()
    pipeline = sharp({
      create: { width: side, height: side, channels: 4, background: '#2f5d4a' },
    }).composite([{ input: innerBuf, left: pad, top: pad }])
  }
  await pipeline.png().toFile(path.join(outDir, name))
}

await writePng('icon-192.png', 192)
await writePng('icon-512.png', 512)
await writePng('icon-maskable-512.png', 512, { padded: true })
console.log('Wrote public/icons/*.png')
```

import { spawnSync } from 'node:child_process'
import { randomUUID } from 'node:crypto'
import withSerwistInit from '@serwist/next'
import type { NextConfig } from 'next'

const revision =
  spawnSync('git', ['rev-parse', 'HEAD'], { encoding: 'utf-8' }).stdout?.trim() ||
  randomUUID()

const withSerwist = withSerwistInit({
  swSrc: 'app/sw.ts',
  swDest: 'public/sw.js',
  disable: process.env.NODE_ENV === 'development',
  cacheOnNavigation: true,
  reloadOnOnline: false,
  additionalPrecacheEntries: [
    { url: '/offline', revision },
    { url: '/fonts/UthmanicHafs1Ver18.woff2', revision },
    { url: '/icons/icon-192.png', revision },
    { url: '/icons/icon-512.png', revision },
    { url: '/icons/icon-maskable-512.png', revision },
  ],
})

const nextConfig: NextConfig = {
  devIndicators: false,
  async headers() {
    return [
      {
        source: '/fonts/:path(.*)',
        headers: [
          {
            key: 'Cache-Control',
            value: 'public, max-age=31536000, immutable',
          },

        source: '/favicon-:name.svg',

- [ ] **Step 2: Create `app/sw.ts`**

```ts
import { defaultCache } from '@serwist/next/worker'
import type { PrecacheEntry, SerwistGlobalConfig } from 'serwist'
import {
  CacheableResponsePlugin,
  CacheFirst,
  ExpirationPlugin,
  Serwist,
} from 'serwist'

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined
  }
}

declare const self: ServiceWorkerGlobalScope

const audioCache = {
  matcher: ({ url, sameOrigin }: { url: URL; sameOrigin: boolean }) =>
    sameOrigin && url.pathname === '/api/quran-audio',
  handler: new CacheFirst({
    cacheName: 'quran-audio-v1',
    plugins: [
      new CacheableResponsePlugin({ statuses: [200] }),
      new ExpirationPlugin({
        maxEntries: 32,
        purgeOnQuotaError: true,
      }),
    ],
  }),
}

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  precacheOptions: { cleanupOutdatedCaches: true },
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    audioCache, // must stay before defaultCache
    ...defaultCache,
  ],
  fallbacks: {
    entries: [
      {
        url: '/offline',
        matcher({ request }) {
          return request.mode === 'navigate' || request.destination === 'document'
        },
      },
    ],
  },
})

serwist.addEventListeners()
```

**Range note:** `<audio>` may request `Range`. Only full `200` bodies are stored; `206` is not cached. First full play online should populate cache; offline replay uses the cached full response when the browser requests without requiring a prior 206 entry. If offline play fails due to Range-only cache misses in testing, add a second NetworkOnly matcher for requests with a `Range` header **before** the CacheFirst rule so range requests go to network when online, and ensure the player triggers at least one non-range (or cache-hit) load — do not add UI; fix only in SW if manual test fails.
