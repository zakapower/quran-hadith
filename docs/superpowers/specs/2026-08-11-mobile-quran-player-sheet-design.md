# Мобильный плеер Корана: мини-бар + bottom sheet — дизайн

Дата: 2026-08-11  
Статус: утверждён

## Цель

Сделать мобильную композицию плеера (не сжатый десктоп):

- свёрнутый мини-бар в духе Spotify;
- раскрытие в лёгкий bottom sheet с чтецом и транспортом;
- десктопный layout (≥721px) без изменений.

## Проблема

На `≤720px` текущий sticky-бар — одна сетка `1fr | auto | 1fr`: аят, prev/play/next, обрезанный чтец и ✕ в одном ряду. Имя чтеца обрезается, иерархия слабая, ощущение «десктоп ужали».

## Зафиксированные решения

| Тема | Выбор |
|------|--------|
| Формат | Мини-бар + bottom sheet |
| Раскрытие | Sheet снизу (~половина экрана) + backdrop |
| Подход | Mobile-only layout в том же `QuranPlayerBar` (не отдельный gesture-heavy sheet) |
| Свёрнутый бар | `аят` · крупный Play/Pause · развернуть · ✕ |
| Prev/Next | Только в sheet |
| Имя чтеца | Только в sheet (полный список) |
| Закрытие sheet | Backdrop / Escape / ✕ в sheet → свернуть; аудио не стопать |
| ✕ в мини-баре | Как сейчас: скрыть плеер + пауза |
| Swipe-to-dismiss | Вне scope v1 |
| Desktop | Без изменений |

## Вне scope (v1)

- swipe-жесты;
- скорость воспроизведения;
- новые чтецы;
- redesign десктопного бара;
- отдельный `QuranPlayerSheet` с gesture-системой.

## UI

### Свёрнутый мини-бар (`max-width: 720px`)

Одна строка:

1. Слева: ref `surah:ayah` (тап открывает sheet).
2. Центр: крупный Play/Pause.
3. Справа: кнопка развернуть (chevron up) + ✕.

Сверху — тонкий progress, как сейчас.  
Чтец и prev/next в свёрнутом виде не показываются.

### Bottom sheet

Открывается снизу поверх контента (~50vh), затемнённый backdrop.

Сверху вниз:

1. Handle / заголовок «Плеер» + кнопка свернуть/закрыть sheet.
2. Крупно `surah:ayah`.
3. Транспорт: Prev · Play · Next (крупные тач-цели ≥2.75rem).
4. Список чтецов (полный текст имён, без ellipsis-кнопки).
5. Блок ошибки + «Повторить», если есть.

Поведение:

- Backdrop / Escape / ✕ sheet → `sheetOpen = false`, плеер остаётся видимым.
- ✕ мини-бара → `close()` (пауза + скрыть бар), sheet тоже закрывается.
- При `visible = false` сбрасывать `sheetOpen`.

## Реализация

### Компоненты

- `QuranPlayerBar.tsx` / `.css` — добавить мобильный layout и sheet UI.
- `QuranAudioContext` — **не менять** аудио-логику; только существующие экшены (`togglePause`, `prevAyah`, `nextAyah`, `setReciter`, `close`, `retry`).

### Состояние

- Локальный `sheetOpen: boolean` в `QuranPlayerBar`.
- Focus: при открытии — в sheet (первая кнопка / контейнер); Escape закрывает sheet.
- Без портала обязательно, если z-index/backdrop работают из fixed-бара; допустим простой fixed overlay sibling.

### Стили

- Брейкпоинт: `max-width: 720px` (как в остальном приложении).
- Safe-area: `env(safe-area-inset-bottom)` на мини-баре и sheet.
- Подправить `padding-bottom` ридера под высоту мини-бара, если sheet/бар перекрывает контент сильнее текущего запаса.

### A11y

- Sheet: `role="dialog"`, `aria-modal="true"`, подпись через `aria-label` / заголовок.
- Кнопка развернуть: `aria-expanded`, `aria-controls`.
- Не ломать существующие aria-label транспорта.

## Критерии готовности

- На iPhone-ширине (~390px) свёрнутый бар без горизонтального overflow и без обрезанного чтеца.
- Sheet открывается/закрывается без остановки аудио.
- ✕ мини-бара по-прежнему останавливает и скрывает плеер.
- Desktop-бар визуально как до изменений.
- Prev/Next доступны с мобилки через sheet.
